# wifi-chat

مستودع مشروع `wifi-chat`.

## الحالة

المشروع مهيأ للربط مع GitHub، والمستودع البعيد خاص.

## الإعداد

1. انسخ `.env.example` إلى `.env`.
2. أدخل القيم المحلية المناسبة في `.env`.
3. لا ترفع `.env` إلى GitHub.

## المتغيرات

راجع `.env.example` لمعرفة أسماء المتغيرات المطلوبة ووصف كل متغير. الملف يحتوي على أمثلة وصفية فقط ولا يحتوي أسرارًا.
